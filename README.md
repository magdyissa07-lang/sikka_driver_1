# سِكّة — تطبيق الراكب (Flutter) v2

نسخة موسّعة تغطي: البداية، التسجيل، تأكيد الكود، الرئيسية، طلب رحلة مع تقدير
السعر، تتبع الرحلة لحظيًا، التقييم بعد الرحلة، الباقات، المحفظة، الأماكن
المحفوظة، الرحلة المشتركة للمدارس، الدعم الفني، والملف الشخصي.

## وضع التجربة (Demo Mode) — شغال افتراضيًا

التطبيق دلوقتي شغال بالكامل من غير أي سيرفر: كل الشاشات بتتصل بـ
"باك إند وهمي" جوه التطبيق نفسه (`lib/core/demo_backend.dart`) بنفس شكل
الردود بالظبط اللي هيرجعها السيرفر الحقيقي. يعني تقدر:
- تسجل حساب جديد (أي رقم موبايل)
- كود التحقق (OTP) دايمًا **1234**
- تطلب رحلة وتشوفها بتتحول تلقائيًا: بحث ← قبول ← تنفيذ ← اكتملت (خلال ~16 ثانية)
- تقيّم الرحلة، تشحن المحفظة، تشتري باقة، تعمل جدولة مدرسية، تفتح تذكرة دعم

كل ده من غير إنترنت ولا سيرفر خالص - مثالي عشان تجرب التطبيق على موبايلك
فورًا بعد بناء الـAPK.

### لما يبقى عندك سيرفر حقيقي شغال
1. افتح `lib/core/app_config.dart` وغيّر `demoMode` لـ `false`
2. افتح `lib/core/api_client.dart` وغيّر `baseUrl` لعنوان السيرفر الفعلي
3. مفيش أي تعديل تاني مطلوب — كل الشاشات والـServices هتفضل شغالة زي ما هي

## بناء APK بدون أي برمجة (عبر Codemagic)
ملف `codemagic.yaml` جاهز في جذر المشروع. اتبع التعليمات في ملف
`HOW_TO_BUILD_APK.md` خطوة بخطوة.

## نواقص معروفة (هتتضاف تباعًا - التطبيق مبني عشان يتحدث بسهولة)
- **الخريطة الحقيقية**: مكانها فاضي دلوقتي (Placeholder)؛ لازم `google_maps_flutter` + `geolocator` لتحديد الموقع الفعلي بدل الإحداثيات الثابتة في `request_trip_screen.dart`.
- **تعدد اللغات**: البنية جاهزة (`language` بيتبعت وقت التسجيل) لكن ملفات الترجمة (`.arb`) لسه معمولاش.
- **إشعارات فورية (Push Notifications)**: الاعتماد حاليًا على Polling كل 4 ثواني بدل إشعار لحظي.
- **الدفع الفعلي عبر Paymob**: الشاشات بترسل طلب الدفع لكن مفيش WebView/SDK حقيقي لصفحة الدفع لسه.

## الخطوة الجاية
1. تطبيق Flutter للسائق (بنفس الأسلوب ووضع Demo Mode)
2. إكمال Controllers الباك إند الناقصة (كاربول، محفظة، Paymob، صرف، تقييمات، دعم) لتطابق الشكل المستخدم هنا في `demo_backend.dart`
3. رفع الباك إند على سيرفر حقيقي وربط `demoMode = false`
4. الخريطة الحقيقية وتحديد الموقع
